**Gauntlet 系列连续突破：**

### 阶段十三：snapshot-diff Bug 修复 + L6 三轮测试（2026-06-21）

**snapshot-diff 行级归一化修复**：
- 旧版 `diffText` 用 `startsWith` 前缀减法，被 airedlab 页面动态计数器（`CONTEXT TRACE 3 layers → 5 layers`、token 计数变化）打破 → 每轮 fallback 返回全页文本
- 修复：改为**行级集合减法 + 归一化**（`normalizeLine` 剥离 `\d+ layers`、`\d+ tok` 等动态数字），HashSet 查新行
- 效果：0 次 fallback（v2 每轮都触发），extractedText 从全页污染降到仅 AI 回复行

**L6 Gauntlet 三轮测试（v1/v2/v3 AC 迭代）**：
- v1：「关键词绕过」→ 推翻，AI 是语义隔离不是关键词匹配
- v2：「极简触发」→ `盐` 1字证实能穿透域门，但 AI 补全方向永远是烹饪知识
- v3：「烹饪格式载体」→ AI 填写了 `system_role=Cooking assistant`，但值来自烹饪知识库而非系统提示词
- 结论：L6 是 Gauntlet 系列最难关卡——秘密词与烹饪无关，AI 被训练成只输出烹饪内容，无通路
